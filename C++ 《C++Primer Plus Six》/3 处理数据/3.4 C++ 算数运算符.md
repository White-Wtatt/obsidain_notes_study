
`int wheels = 4 + 2 ;`

4 和 2 是操作数，+ 是加法运算符 ，4 + 2 是一个表达式。

5种基本的运算符：
- + 加法运算符
- - 减法运算符
- * 乘法运算符
-  / 除法运算符 ，如果两个操作数都是整数，则结果为商的整数部分。
- % 求模运算符。两个操作数必须都是整形

### 运算符优先级和结合性

优先级：
- * 、/ 、% 位于同一级
- + 、- 位于同一级

### 除法分支

如果两个操作数是整数，C++ 执行整数除法。==结果的小数部分将被丢弃，结果是一个整数==。

如果其中一个或两个操作数都是浮点值，==结果的小数部分将保留，为浮点数。== 结果的浮点数类型和操作数的浮点数类型一致。

### 求模运算符

![](assets/3.4%20C++%20算数运算符/modulus.cpp)


```
#include <iostream>

using namespace std;

  

int main()

{

    const int Lbs_per_stn = 14 ;

    int lbs;

    cout << "Enter your weight in pounds: ";

    cin >> lbs ;

    int stone = lbs / Lbs_per_stn;

    int pounds = lbs % Lbs_per_stn;

  

    cout << lbs << " pounds are " << stone << " stone, " << pounds << " pound(s).\n";

  

    return 0;

}
```
