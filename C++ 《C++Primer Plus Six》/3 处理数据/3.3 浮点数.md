
## 书写浮点数

第一种：使用常用的标准小数点表示法

12.34
0.00023
8.0

8.0是浮点数而不是整数，小数点确保该数字以浮点格式表示。

第二种：E 表示法

2.52e+8  //$2.52*10^{8}$
8.33E-4  //$8.33*10^{-4}$
7e5  //same as 7.0E+5

E 表示法确保数字以浮点格式存储，即使没有小数点。==数字中不能有空格==


## 浮点类型

有三种浮点类型： `float` , `double` , `long double`

有效位是数字中有意义的位。

例：14179m 是5个有效位。

约为 14000m 是2个有效位，三个零是占位符。

14.179km 仍然是5个有效位。


`float` 至少32位
`double` 至少48位，通常为64位
`long double` 通常为 80、96或128位

## 浮点常量

默认情况下，==一般的浮点常量（如8.24和2.4E+8)都的属于double类型。==如果要求float类型，在后面使用f或F后缀；long double 类型，使用 l 或 L （推荐）类型。

1.234f
2.45E+2F
2.25L

## 浮点数的优缺点

优点：
- 可以表示整数之间的值
- 由于有缩放因子，可以表示的范围大

缺点：
- 浮点运算的速度通常比整数运算慢
- 精度低于整数运算

```
#include <iostream>

using namespace std;

  

int main()

{

    float a = 2.34E+22F;

    float b = a + 1.0f;

  

    cout << "a = " << a << endl;

    cout << "b - a =  " << b - a << endl;

  

    return 0;

}
```
