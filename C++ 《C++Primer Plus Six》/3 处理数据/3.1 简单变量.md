
## 变量名

### 命名规则：

- 在名称中只能使用字母字符、数字和下划线（ _ )
- 名称的第一个字符不能是数字
- 区分大写字符和小写字符
- 不能将C++关键字用作名称
- 以两个下划线打头或以下划线和大写字母打头的名称被保留给实现（编译器及其使用的资源）使用。以一个下划线开头的名称被保留给实现，用作全局标识符。
- C++对于命名的长度没有限制，名称中所有的字符都有现实意义。


## 整型

`short` : 至少 16 位
`int` : 至少 16 位
`long` : 至少 32 位
`long long` : 至少 64 位



![](assets/3.1%20简单变量/limits.cpp)

```
#include <iostream>

#include<climits>

using namespace std;

  

int main()

{

    int n_int = INT_MAX;

    short n_short = SHRT_MAX;

    long n_long = LONG_MAX;

    long long n_llong = LLONG_MAX;

  

    cout << "int is " << sizeof n_int << " byets." << endl;

    cout << "short is " << sizeof n_short << " bytes." << endl;

    cout << "long is " << sizeof n_long << " bytes." << endl;

    cout << "lomh long is " << sizeof n_llong << " bytes." << endl;

    cout << endl;

  

    cout << "Maximum values:" << endl;

    cout << "int: " << n_int << endl;

    cout << "short: " << n_short << endl;

    cout << "long: " << n_long << endl;

    cout << "long long: " << n_llong << endl << endl;

    cout << "Minimum int values = " << INT_MIN << endl;

    cout << "Bits per byte = " << CHAR_BIT <<  endl;

  

    return 0;

}
```

### 运算符 `sizeof` 和头文件 `limits` 

`sizeof n_int` 可以换成 `sizeof (int)`:
对类型名（如 `int` ）使用 `sizeof` 运算符时，应该加（ ）；但对变量名（如 `n_int` ），（ ）是可选的。

 头文件 `climits` 定义了符号常量来表现类型的限制。


| 符号常量         | 表示                        | 备注           |
| ------------ | ------------------------- | ------------ |
| `CHAR_BIT`   | `char` 的位数                | 8            |
| `CHAR_MAX`   | `char` 的最大值               | 127          |
| `CHAR_MIN`   | `char` 的最小值               | -128         |
| `SCHAR_MAX`  | `signed char` 的最大值        | 127          |
| `SCHAR_MIN`  | `signed char` 的最小值        | -128         |
| `UCHAR_MAX`  | `unsigned char` 的最大值      | 255          |
| `SHRT_MAX`   | `short` 的最大值              | 32676        |
| `SHRT_MIN`   | `short` 的最小值              | -32678       |
| `USHRT_MAX`  | `unsigned short` 的最大值     | 65535        |
| `INT_MAX`    | `int` 的最大值                | $2^{15} -1$  |
| `INT_MIN`    | `int` 的最小值                | $- 2^{15}$   |
| `UINT_MAX`   | `unsigned int` 的最大值       | $2^{16} -1$  |
| `LONG_MAX`   | `long` 的最大值               | $2^{31}-1$   |
| `LONG_MIN`   | `long` 的最小值               | $-2^{31}$    |
| `ULONG_MAX`  | `unsigned long` 的最大值      | $2^{32} - 1$ |
| `LLONG_MAX`  | `long long` 的最大值          | $2^{63}-1$   |
| `LLONG_MIN`  | `long long` 的最小值          | $-2^{63}$    |
| `ULLONG_MAX` | `unsigned long long` 的最大值 | $2^{64}-1$   |
