
1. 编写一个小程序，要求用户使用一个整数指出自己的身高（单位为英寸：foot）,然后将身高转换为自己英尺（inch）和英寸（foot）。该程序使用下划线来指示输入位置。另外，使用一个 const 符号常量来表示转换因子。

![](assets/3.5%20编程练习/1.cpp)

```C++
#include <iostream>

using namespace std;

  

int main()

{

    const int ft_trans_in = 12;

  

    cout << "Please enter your height in inches_____\b\b\b\b\b ";

    int in ;

    cin >> in;

    int ft = in / ft_trans_in;

    int in_s = in % ft_trans_in;

  

    cout << "You height is " << ft << " feet and " << in_s << " inches.\n";

  

    return 0;

}
```
