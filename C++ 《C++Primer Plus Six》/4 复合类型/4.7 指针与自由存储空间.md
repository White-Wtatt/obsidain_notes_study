
计算机程序在存储数据时必须跟踪的3种基本属性：
- 信息存储在何处；
- 存储的值为多少；
- 存储的信是什么类型。

使用一种策略：定义一种简单变量。声明语句指出了值的类型和符号名，还让程序为值分配内存，并在内存跟踪该内存单元。

另一种策略：以指针为基础，指针是一个变量，其存储的是值的地址。而不是值本身。

找到常规变量的地址，只需对变量应用地址运算符（&）。

```C++
#include <iostream>

using namespace std;

  

int main()

{

    int donuts = 6;

    double cups = 4.5;

  

    cout << "donuts value = " << donuts;

    cout << " and donuts address = " << &donuts << endl;

    // Note: You may need to use unsigned (&donuts)

    // and unsigned (&cups)

    cout << "cups value = " << cups;

    cout << " and cups address = " << &cups << endl;

    return 0;

}
```

指针名表示的是地址。* 运算符被称为间接值或解除引用运算符，将其应用于指针，可以得到该地址处存储的值。

```C++
#include <iostream>

using namespace std;

  

int main()

{

    int update = 6;

    int *p_update;

    p_update = &update;

  

    cout << "Value: update = " << update;

    cout << ", *P_update = " << *p_update << endl;

  

    cout << "Addresses: &updates = " << &update;

    cout << ", p_update = " << p_update << endl;

  

    *p_update = *p_update - 1;

    cout << "Now update = " << update << endl;

    return 0;

}
```
