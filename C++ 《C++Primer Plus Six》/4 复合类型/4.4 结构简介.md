同一个结构可以存储多种类型的数据。

结构是用户定义的类型，结构声明定义了这种类型的数据属性。

创建结构：
- 定义结构描述 —— 它描述并标记了能够储存在结构中的各种数据类型。
- 按描述创建数据变量（结构数据对象）。

Example：

```C++
struct inflatable
{
	char name[20];
	float volume;
	double price;
};
```

- 关键字 struct 表明，这些代码定义的是一个结构的布局。
- 标识符 inflatable 是这种数据格式的名称，可以创建 inflatable 类型的变量。
- 大括号中包含的是结构存储的数据类型的列表，其中每个列表项都是一条声明语句。
- 列表中的每一项都称为结构成员。

```C++
inflatable hat;  //hat is a structure variable of type inflatable

inflatable woopie_cushion; // type inflatable variable

```

 hat 的类型是 inflatale 。使用 ==成员运算符（.）== 来访问各个成员。

```C++
hat.volume   //结构的 volume 成员

hat.price   //指的是 price 成员
```



## 在程序中使用结构


![](assets/4.4%20结构简介/structur.cpp)

```C++
#include <iostream>

using namespace std ;

  

struct inflatable

{

    char name[20];

    float volume;

    double price;

};

  

int main()

{

    inflatable guest =

    {

        "Glorious Gloria",

        1.88,

        29.33,

    };

  

    inflatable pal =

    {

        "Audacious Arthur",

        3.12,

        32.99,

    };

  

    cout << "Expand your guest list with " << guest.name;

    cout << " and " << pal.name << "!\n";

    cout << "You can have both for $";

    cout << guest.price + pal.price << "!\n";

    return 0;

}
```

结构声明的位置：
- 将声明放在 main( ) 函数中，紧跟在开始的括号后面中 （内部声明）
- 将声明放在 main( ) 前面 （外部声明）


```C++
inflatable guest =

    {

        "Glorious Gloria",

        1.88,

        29.33,

    };
```

使用逗号分隔值列表，并将这些值用花括号括起来
可以每个值占一行，也可以将它们全部放在同一行中

## 结构初始化

可以省略括号
```C++
inflatable duck 
{
	"Daphne",
	0.12,
	9.98,
};
```

如果大括号内未包含任何东西，各个成员都将设置为零。

## 其他结构属性


C++ 使用户定义的类型与内置类型尽可能相同，例如：
- 可以将结构作为参数传递给函数
- 可以让函数返回一个结构
- 可以使用赋值运算符（=）将结构赋给另一个同类型的结构

![](assets/4.4%20结构简介/assgn_st.cpp)

```C++
#include <iostream>

using namespace std;

  

struct inflatable

  

{

    char name[20];

    float volume;

    double price;    /* data */

};

  
  

int main()

{

    inflatable bouquet

    {

        "Sunflowers",

        0.20,

        12.49,

    };

  

    inflatable choice;

  

    cout << "bouquet: " << bouquet.name << " for $" << bouquet.price

    << endl;

  

    choice = bouquet ;

  

    cout << "choice: " << choice.name << " for $" << choice.price

    << endl;

  

    return 0;

}
```
