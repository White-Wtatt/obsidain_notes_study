#### C 风格字符串

存储在 char 数组中以空字符结尾，写作 `\0` ,其ASCII 码为 0 ，用来标记字符串的结尾。

```C++
char dog[8] = {'b','e','a','u','x',' ','I','I'}; //not allowed

char cat[8] {'f','a','t','e','s','s','a','\0'}; //a string

```

dog 数组由于没有空字符，cout 打印 dog 字符时，先打印数组中的 8 个字母，并接着将内存中随后的各个字节解释为要打印的字符，知道遇到空字符为止。


#### 字符串常量

```C++

char bird[11] = "Mr.Cheeps";

char fish[ ] = "Bubbles";

```

用引号括起的字符串隐式地包括结尾的空字符。
需要确保数组足够大，能够存储字符串中所有字符—— 包括空字符。

#### 字符串常量（双引号）和字符常量（单引号）

字符常量（如 ‘s'）是字符串编码的简写表示。在ASCII 系统上，'s' 只是 83 的另一种写法

`char shirt_size = 's';`

这个语句将 83 赋给 shirt_size

"s" 表示的是两个字符（字符 S 和  \0 ) 组成的字符串， "s" 实际表示的字符串所在的内存地址。

### 拼接字符串常量

将两个用引号括起的字符串合并为一个。任何由两个空白（空格、制表符、换行符）分隔的字符串常量自动拼接成一个。

```C++
cout << "I like my cat"" which is so cute.\n";

cout << "I like my  cat which is so cute.\n";

cout << "I like my cat"
"which is so cute.\n";

```

### 在数组中使用字符串

将字符串存储到数组中，有两种方法：

- 将数组初始化为字符串常量（char）
- 将键盘或文件输入读入到数组中


![](assets/4.2%20字符串/strings.cpp)

```C++
#include <iostream>

#include <cstring>


using namespace std;
  

int main()

{

    const int Size = 15;

    char name1 [Size];

    char name2 [Size] = "C++owboy";

  

    cout << "Howdy!I'm " << name2;

    cout <<"!What's your name?\n";

    cin >> name1;

    cout << "Well, " << name1 << ",your name has ";

    cout << strlen(name1) << " letters and is stored\n";

    cout << "in an array of " << sizeof(name1) << " bytes.\n";

    cout << "Your initial is " << name1[0] << ".\n";

  

    name2[3] = '\0';

    cout << "Here are the first 3 characters of my name: ";

    cout << name2 << endl;

  

    return 0;

}
```

`sizeof` 运算符指出整个数组的长度：15 字节

`strlen()` 函数返回的是存储在数组中的字符串长度，并且只计算可见的字符。

`name2[3] = '\0';` 将第三个字符设置为空字符，使得字符串在第三个字符后结束（忽略后面的字符）。

### 每次读取一行字符串输入

#### 面向行的输入： `getline()`

`getline()` 函数读取整行，它使用通过回车键输入的换行符来确定输入结尾。使用 `cin.getline()` 

格式：cin.getline(数组名，元素个数)


![](assets/4.2%20字符串/instr2.cpp)


```C++
#include <iostream>

  
using namespace std;

  
int main()

{

    const int ArSize = 20;

  

    char name[ArSize];

    char dessert[ArSize];

  

    cout << "Enter your name :\n";

    cin.getline (name,ArSize);

  

    cout << "Enter your favorite dessert:\n";

    cin.getline(dessert,ArSize);

  

    cout << "I have some delicious " << dessert << " for you "

    << name;

  

    return 0;

}
```

#### 面向行的输入： `get()`

get 有几种变体。其中一种变体的工作方式与 `getline()` 类似 ，他们接受的参数相同，解释参数的方式也相同，并且都读取到行尾。

但 get 并不再读取并丢弃换行符，而是将其留在输入队列中。

```C++
cin.get(name,Arsize);

cin.get(dessert.Arsize);
```

由于第一次调用后，换行符将留在输入队列中，因此第二次调用时看到的第一个字符便是换行符。因此 get() 认为已经到达行尾，而没有发现任何可读的内容。

使用不带任何参数的 `cin.get()` 调用可读取下一个字符（即使是换行符）

```C++
cin.get(name,ArSize);

cin.get();

cin.get(dessert,ArSize);
```


可以将两个类成员函数拼接起来

`cin.get(name,ArSize).get()`

把输入中连续的两行分别读入数组中 name1 和 name2 中
`cin.getline(nmae1,ArSize).getline(Name2,ArSize);`
