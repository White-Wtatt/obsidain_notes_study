#### C 风格字符串

存储在 char 数组中以空字符结尾，写作 `\0` ,其ASCII 码为 0 ，用来标记字符串的结尾。

```C++
char dog[8] = {'b','e','a','u','x',' ','I','I'}; //not allowed

char cat[8] {'f','a','t','e','s','s','a','\0'}; //a string

```

dog 数组由于没有空字符，cout 打印 dog 字符时，先打印数组中的 8 个字母，并接着将内存中随后的各个字节解释为要打印的字符，知道遇到空字符为止。


#### 字符串常量

```C++

char bird[11] = "Mr.Cheeps";

char fish[ ] = "Bubbles";

```

用引号括起的字符串隐式地包括结尾的空字符。
需要确保数组足够大，能够存储字符串中所有字符—— 包括空字符。

#### 字符串常量（双引号）和字符常量（单引号）

字符常量（如 ‘s'）是字符串编码的简写表示。在ASCII 系统上，'s' 只是 83 的另一种写法

`char shirt_size = 's';`

这个语句将 83 赋给 shirt_size

"s" 表示的是两个字符（字符 S 和  \0 ) 组成的字符串， "s" 实际表示的字符串所在的内存地址。
