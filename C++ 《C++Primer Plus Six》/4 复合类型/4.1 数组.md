数组声明：
- 存储在每个元素中的值的类型
- 数组名
- 数组中的元素数

格式： `typeName arrayname [arrysizeSize]`

## 数组初始化

```C++
int crad [4] = {3,,6,8,10} ; // okay

int hand [4] ;   // okay

hand [4] = {5,6,7,8} ; //not allowed

hand = card ;  //not allowed

hand [0] = 5 ;  //okay

```

### 初始化规则

初始化数组时，。提供的值可以少于数组的元素条目。

`flaot hotelTips [5] = {5,0,2.5};`

其他的元素设置为 0 

把数组中所有元素都初始化为 0 —— 把显式地将第一个元素初始化为 0

`long totals [500] = {0};`

如果初始化数组时方括号内（[ ]) 为空，C++编译器将计算元素个数。

`short things[] = {1,2,3,4};`

### C++ 11 数组初始化方法

初始化数据时，可省略等号（=）

`double earning[4] {1.2e4,1.6e6,1.1e4,1.7e4};`

可不在大括号内设置任何东西，这将把所有元素都设置为零

`float blances [100] {};`

初始化禁止缩窄转换

```C++
long plifs[] = {25,46,3.0};  //not allowed

char slifs[] = {'h','i',11220011,'\0'};  //not allowed

char tlifs[4] {'h','i',112,'\0'}; // allowed
```
