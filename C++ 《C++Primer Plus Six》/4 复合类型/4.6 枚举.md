
C++ 的 enum 工具提供了另一种创建符号常量的方式，这种方式可以代替 const。

```C++
enum spectrum {red,orange,yellow,green,blue,violet,indigo,ultraviolet};
```

- spectrum 成为型类型的名称； spectrum 被称为枚举（enumeration)
- 将 red , orange , yellow 等作为符号常量，他们对应整数值 0~7 。这些常量叫作 枚举量（enumerator)

可以用枚举名来声明这种类型的变量：

`spectrum band;`

## 属性

在不进行强制类型转换的情况下，只能将定义枚举时使用的枚举量赋给这种枚举的变量。

```C++
band = blue; // valid

band = 2000; // invalid
```

spectrum 变量受到限制，只有8个可能的值。

对于枚举，只定义了赋值运算符，没有定义算术运算。

```C++
band = orange; // valid

++band;   // not valid,

band = orange + red;

```


 枚举量是整型，可被提升为 int 类型，但 int 不能自动转换为枚举类型。

```C++
int color = blue; 

band = 3; //invalid,int not converted to spectrum

color = 3 + red; // valid,red converted int

```



```C++
band = orange + red; //not valid
```

非法的原因：确实没有为枚举定义运算符 + ，但用于算术表达式中时，枚举将被转换为整数，因此表达式 orange + red 将被转换为 1+0 。这是一个合法的表达式，但其类型为 int ,不能将其赋给类型为 spectrum 的变量 band.

如果 int 值是有效的，则可以通过强制类型转换，将它赋给枚举变量：
```C++
band = spectrum(3);
```

如果对一个不适当的值进行强制类型转换，结果将不确定：
```C++
band = spectrum(1000); //undefined
```


## 设置枚举量的值

可以使用赋值运算符来显示地设置枚举量的值：
```C++
enum bits = {one = 1,two = 2};
```

指定的值必须是整数。

```C++
enum bigstep {first,second = 100,third};
```
