```C++
#include <iostream>

using namespace std;

  

int main() {       // main 是程序开始执行的地方

    cout << "Hello, World!" << endl;    

    return 0;

}
```


-  // 是注释
-  #include 是预处理编译指令
-  `<iostream>` 是头文件，包含了程序中必须的或有用的
-  `cout` 是输出语句
-  `return 0` 是结束，终止main函数

## `main`

主函数的函数头


## 注释

一般以 `//` 为单行注释

`/*......*/` 为多行注释


## C++预处理器

`#include <iostream>`  是编译指令，将 `iostream` 文件的内容添加到程序中来

使用 `cin` `cout`  就必须包含 `iostream` 

`cin` 是 `istream`文件中的，`cout`  是 `ostream` 文件中的

## 名称空间

使用 `iostream.h` , 就不需要

使用 `iostream` , 使用 `using namespace std`,
不使用的情况下，`std::cout` `std::endl`
