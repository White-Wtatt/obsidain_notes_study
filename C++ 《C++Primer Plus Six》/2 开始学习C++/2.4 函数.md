## 使用有返回值的函数


![](assets/2.4%20函数/sqrt.cpp)


```
#include<iostream>

#include<cmath>

using namespace std;

  

int main()

{

    double area;

    cout << "Enter the floor area , in square feet, of the building: ";

    cin >> area;

    double side;

    side = sqrt (area);

    cout << "The side length of the square footage is: " << side << endl;

    return 0;

}
```


表达式`side = sqrt (area)` 将调用`sqrt()`函数

被调用的函数叫做被调用函数（called function），包含函数调用的函数叫做调用函数（calling function）

`area` 叫作 参数 ，`side`  接受并输出的值叫作 ==返回值（return value）==

要使用 ==`sqrt`== , 需要声明 ==`cmath`== 的头文件


## 函数变体

需要多个参数的函数，在括号内使用逗号

函数调用必须必须包含括号，即使没有参数

还有没有返回值的函数

有返回值的函数称为==函数（function）==，没有返回值的函数称为==过程（procedure）或 子程序（subroutine）==。

### 函数格式

`sisom()` 函数的定义和 `main()` 的定义采用的格式相同。

格式模板：
`type functionname(argumentlist)`
`{`
`statements`
`}`

定义 `sidom()` 位于 `main()` 的后面

### 函数头

`void sidom (int n)` 是 `sidom()`的函数头

`void` 表示 `sidom（）` 没有返回值，因此调用 `sidom()` 不会生成可在主函数中将其赋给变量的数字。

括号中的 `int n` 表明，使用 `sidom()` 函数时，应该提供一个 int 参数。



## 用户定义的有返回值的函数


![](assets/2.4%20函数/convert.cpp)

```
#include <iostream>

using namespace std;

int stonetolb(int);

  

int main()

{

    int stone;

    cout << "Enter the weight in stone: ";

  

    cin >> stone;

    int pounds = stonetolb(stone);

  

    cout << stone << " stone =  ";

    cout << pounds << " pounds." << endl;

    return 0;

  

}

  

int stonetolb(int sts)

{

    return sts * 14;

}
```


在 `main()` 中，程序使用 `cin` 来给变量 `stone` 提供一个值。这个值被作为参数传递给 `stonetolb()` 函数 ， 在这个函数中，这个值被赋给变量 `sta` 。

### 在多函数程序中使用 using 编译指令

让程序能够访问名称空间 `std` 的方法：

- 将 `using namespace std` 放在函数定义之前 ，让文件中所有的函数能够使用名称空间 `std` 中所有的元素。
- 将 `using namespace std` 放在特定的函数中，让该函数能够使用名称空间 `std` 中的所有文件
- 在特定的函数中使用类似 `using std::cout` 这样的编译指令，让该函数能够使用指定的元素，如 `cout`.
- 完全不使用编译指令 using ，而在需要使用名称空间 `std` 中的元素时，使用前缀 `std::`
