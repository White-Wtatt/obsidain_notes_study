定义了一个叫 `square` 的新函数， `x` 叫做形式参数（形参）

如何定义函数：
1. `def` 语句：指明函数的名称和一个以逗号分隔的形式参数列表
2. `return` 语句（函数体），写的是返回的表达式


```python
def <函数名>(<形式参数列表>):
	return <返回表达式>
```

函数的第二行必须进行缩进，返回表达式会作为新定义的函数的一部分存储，并且仅在最终调用该函数时才进行求值。

```python
from operator import add

def sum_square(x,y):
	return add(square(x),square(y))
```
