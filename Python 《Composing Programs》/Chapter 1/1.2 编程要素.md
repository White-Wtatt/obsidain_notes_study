## 调用表达式

是一种复合表达式，

![](assets/1.2%20编程要素/file-20260110144745686.png)

这个调用表达式包含**子表达式**（subexpressions）：运算符（operator）是一个表达式，它位于括号之前，而括号里面是一个以逗号分隔的操作数表达式（operand expressions）的列表。

### 函数表示法的三个优点：
- **函数可以接受任意数量的参数**
- 函数可以直接扩展为**嵌套表达式**（nested expressions），其元素本身就是复合表达式。调用表达式的**嵌套结构在括号中是完全明确的**。
- Python 支持使用中缀表示法的常见数学运算符（如 `+` 和 `-`）之外，但**任何运算符都可以表示为一个带有名称的函数**。


## 导入库函数

Python 将已知函数和其他东西组织起来放入到了**模块**（module）中，而这些模块共同组成了 Python 标准库。我们要使用的时候需要**导入**（import）它们。

`math` 模块提供各种数学函数

`operator` 提供中缀运算符对应的函数：`add sub mul`

格式： from 模块名称 import 模块里的命名属性

## 函数分类

纯函数（Pure function）：只有输入 （参数），只有输出（返回值）。

纯函数的特性是：除了返回值之外没有别的**副作用**，而且**同样的参数永远返回完全相同的结果**。

![](assets/1.2%20编程要素/file-20260110144805509.png)

非纯函数（Non-pure functions) : 除了返回值之外，调用它们还会产生**副作用**（side effect），也就是改变解释器或计算机的某种状态。


![](assets/1.2%20编程要素/file-20260110144817947.png)

`print` 返回的值永远是 `None` —— Python 里**代表“空”的特殊值**。交互式解释器不会主动打印 `None` 值，所以上面例子中看到的 `1 2 3`，其实是 `print` 在执行过程中主动打印出来的**副作用**，而不是它的返回值。

![](assets/1.2%20编程要素/file-20260110144810640.png)

### 纯函数的优势：

1.  `print` 的例子已经说明，非纯函数在子表达式位置往往会出问题；而 `max、pow、round` 这类纯函数却可以随意嵌套
2. 纯函数**极易测试**：同样的参数永远得到同样的返回值，直接和预期结果对比即可。
3. 第 4 章会讲到，编写**并发**程序时（多个表达式可能同时求值），纯函数几乎是唯一安全的选择。
